Tanpa API URL, aplikasi menggunakan data dummy di memori browser. Data tidak tersimpan saat halaman ditutup.

Setelah API URL dikonfigurasi, semua data tersimpan permanen di Google Spreadsheet.
📋 Panduan Setup Backend
1. Buat Google Spreadsheet baru
Catat Spreadsheet ID dari URL browser
2. Buka Apps Script
Extensions → Apps Script → copy semua file .gs
3. Isi Spreadsheet ID
SPREADSHEET_ID: 'id-mu-di-sini'
4. Jalankan setupSpreadsheet()
Pilih fungsi → Run → izinkan akses
5. Deploy sebagai Web App
Deploy → New deployment → Web App → Execute as: Me → Anyone
